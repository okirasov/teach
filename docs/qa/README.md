# Тестовая документация

`Teach — тестовая документация QA.docx` — пошаговые тест-кейсы для junior QA: подготовка (сборка, вход, токен), дымовой прогон новой сборки, 75 кейсов по областям (вход и интро, «Сегодня», мастер, урок, разбор, повторы, справочники, голос, озвучка, настройки, устойчивость, API), шаблон отчёта о баге, что не считается багом, словарь.

Документ генерируется скриптом, чтобы правки делать в коде, а не в Word:

```bash
python3 -m venv .venv && .venv/bin/pip install python-docx
.venv/bin/python docs/qa/make_qa_doc.py
```
