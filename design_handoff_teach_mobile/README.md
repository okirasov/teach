# Handoff: Teach — мобильное приложение (iOS-first)

## Overview
Teach — мобильный репетитор на базе интервальных повторов: уроки «объяснение → практика без подсказок → разбор», ошибки становятся записями и возвращаются как карточки повторов, справочники конденсируют пройденное, миссия предмета версионируется. Пакет описывает полный кликабельный прототип: авторизация, 4 вкладки, сессия урока, голосовой ввод, создание предмета, настройки, профиль (ru/en, light/dark).

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, собранные в HTML** (`Teach - Прототип.dc.html` + `ios-frame.jsx` + `support.js`). Это прототип, показывающий целевой вид и поведение, а НЕ production-код для копирования. Задача — **воссоздать эти экраны в целевом стеке** (React Native / SwiftUI / Flutter — выбрать по проекту, если стека ещё нет) по паттернам выбранного фреймворка. Логика прототипа (класс `Component` внутри dc.html) — читаемая карта состояний и переходов, используйте её как спецификацию поведения.

`DESIGN.md` — основная спецификация: токены, компоненты, все экраны, правила метода. Этот README дополняет её деталями имплементации.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы и тексты финальные — воссоздавать пиксель-в-пиксель. Единственные прототипные упрощения: распознавание речи симулировано (транскрипт печатается по словам), генерация урока — таймер 4 с, данные уроков захардкожены.

## Screens / Views
Карта экранов (роутинг прототипа): `auth | main(tab: today | reviews | refs | mission) | session | recap | setup | manage | profile | refdetail`.
Подробные описания всех 11 экранов — в DESIGN.md §4. Ключевые размеры:
- Экран: safe-area сверху ~64px, боковые поля 20px, нижний отступ 30px.
- Primary-кнопка h54 r14; шапка сессии: ×-кружок 36px, чип контекста по центру, счётчик mono справа.
- Прогресс: сегменты h4 r2 gap5. Карточки r14–16, padding 14–16, рамка 1px var(--line).
- Таб-бар: 4 пункта, 11.5px, active var(--ink)/500, разделитель сверху var(--lineSoft).
- Хит-таргеты ≥44px.

## Interactions & Behavior
- **Сессия**: выбор варианта подсвечивает (--sel); «Ответить» фиксирует попытку → верный вариант mint+«ВЕРНО», неверный выбор errBg+«ВАШ ВЫБОР», фидбек-карточка с объяснением (+«КАК ПРАВИЛЬНО» при ошибке ввода). CTA-цепочка: К практике → Ответить → Дальше → К разбору. Кнопка disabled (--dis) пока нет выбора/текста.
- **Голос** (шаг ввода, если включён у предмета): тап по кнопке микрофона → запись (цвет --err, ореол 0 0 0 8px rgba(err,.15), подпись «Слушаю…»), транскрипт печатается в поле ~240 мс/слово, повторный тап — стоп, текст правится вручную. Голос никогда не блокирует прогресс.
- **Разбор**: карточки «УЙДЁТ В ПОВТОРЫ» — ошибка «через 1 день», успех «через 4 дня»; «Готово» увеличивает счётчик очереди на Сегодня и добавляет записи в Повторы→«Позже».
- **Новый предмет**: 4 шага с прогрессом (тема → миссия → источники с исключением по тапу → план); после «Готово» карточка «Готовится…» → через ~4 с «Урок готов» (в проде — push/фон). Первый урок — диагностика: калибровочный выбор без правильного ответа (бейдж «ПРИНЯТО») + свободный рассказ.
- **Справочники**: сегменты предметов; живой поиск по названиям и строкам; фильтр «Мои слабые места»; детальный экран — поиск внутри + таблица «термин 126px | описание», подразделы mono-заголовками, бейдж «ОШИБКА».
- **Настройки предмета**: тумблеры и пиллы применяются мгновенно; выключение «Голос в этом курсе» убирает кнопку микрофона из сессий и скрывает «Язык распознавания» (два пилла: язык интерфейса / язык предмета); «Удалить предмет» — двухшаговое подтверждение (errBg-карточка + Да/Оставить), удаляет предмет, его записи и очередь.
- **Профиль** (без скролла): карточка аккаунта с двумя числами (за месяц / сегодня); группы Напоминания (Утро/Вечер, Тихие выходные) · Повторы (лимит в день 20/40/80/Нет) · Голос (Удерживать / Без рук) · Приложение (язык ru/en — мгновенная смена всех строк UI, контент уроков не переводится; тема light/dark — подмена токенов). «Выйти» — двухшаговое подтверждение → auth; локальные данные на устройстве сохраняются.
- **Шапка**: логотип + дата + аватар на каждом экране; на Профиле и Настройках предмета вместо знака — ×. Заголовки вкладок — h1 + короткий подтекст справа в той же строке.
- Переходы между экранами в прототипе мгновенные; при порте — платформенные (push/modal), без изысков.

## State Management
Из логики прототипа (state класса Component):
- `screen, tab` — роутинг; `lang ('ru'|'en'), theme ('light'|'dark'), user {name, provider}`.
- Сессия: `subj, step, sel, checked, input, results[], rec` (запись голоса).
- Данные: `done{subjId}, added` (прирост очереди), `reviewLog[]` (новые карточки), `custom {topic, mission, ready}`, `removed{}`.
- Настройки per-предмет: `cfg{id: {pause, dur(3|5|10), lim(10|20|50), diff('comfy'|'edge'), voice, vlang('ui'|'lesson')}}`.
- Глобальные: `g{rem('morning'|'evening'), weekendOff, cap(20|40|80|0), mode('ptt'|'hands')}`; `confirmOut` — состояние подтверждения выхода.
- Миссии: `missions{id: {cur, hist[]}}` — версии только добавляются.
- Справочники: `refSubj, refQ, weakOnly, refId, refDQ`.
- Модель урока: шаги `{type: 'explain'|'choice'|'input', prompt, options?, correct?, tokens?, answer?, explain, recTitle, recNote, voice?}` — recTitle/recNote = LearningRecord. correct: -1 — калибровка без правильного ответа.
- Прод-замены: интервалы 1/4 дня → FSRS или SM-2; проверка ввода по токенам → нормальная оценка; таймер генерации → фоновая задача; Повторы и Справочники — офлайн-хранилище.

## Design Tokens
Полная таблица light/dark — DESIGN.md §2. База: фон #FAF6EE, карточки #FFF, текст #12281C, акцент #1C4634, мягкая подложка #DCEEDF, янтарь записей #835A0E/#F5EAD2, деструктив #B4552F. Тёмная: фон #0F1B15, карточки #17271D, акцент #9FD6B4.
Шрифты: Golos Text (UI, 400–700), IBM Plex Mono (данные/кикеры, 400–500) — Google Fonts, кириллица.
Радиусы: 10 (пиллы h42), 7 (чипы-статусы, сегменты), 9 (подложка сегмент-контрола), 14–16 (карточки/кнопки), 12 (инпуты). Кикеры: mono 10–10.5px UPPERCASE ls .08–.1em — только в сессии/разборе/справочниках; заголовки групп в Профиле — Golos 13px 500.
