# Teach — дизайн-спецификация для имплементации

Прототип-источник: `Teach - Прототип.dc.html` (интерактивный, все флоу кликабельны).
Направление бренда: **1b «Интервал»** — спокойная глубокая зелень, метафора интервальных повторов.

## 1. Бренд

### Логотип
- Словотип: `teach` строчными, Golos Text SemiBold, letter-spacing −0.3…−0.5px.
- Знак: буква **t**, перекладина — точки с растущим шагом (метафора интервалов);
  последняя точка — контурная, янтарная (#DFA032) — «ещё не наступивший повтор».
- SVG знака (viewBox 0 0 96 96):
  ```svg
  <rect x="16" y="14" width="9" height="64" rx="4.5" fill="#1C4634"/>
  <circle cx="20.5" cy="30" r="5" fill="#1C4634"/>
  <circle cx="37" cy="30" r="5" fill="#1C4634"/>
  <circle cx="56" cy="30" r="5" fill="#1C4634"/>
  <circle cx="79" cy="30" r="5.5" stroke="#DFA032" stroke-width="3" fill="none"/>
  ```
- Иконка приложения: знак на хвойном #1C4634 (тёмная) или кремовом #FAF6EE (светлая).

### Типографика
- **Golos Text** (400/500/600/700) — весь UI и заголовки. Кириллица + латиница.
- **IBM Plex Mono** (400/500) — данные, кикеры, чипы-статусы, счётчики (`ПОВТОРЫ · СЕГОДНЯ`, `2/5`, интервалы).
- Размеры (мобайл): h1 экрана 23–26px/1.2 semibold; вопрос практики 19px/1.45;
  основной текст 15px/1.6; вторичный 12.5–13px/1.4–1.5; кикеры 10–10.5px mono, letter-spacing .08–.1em, UPPERCASE.

## 4. Экраны и флоу (все есть в прототипе)

### 4.1 Авторизация
Логотип + слоган → кнопки «Продолжить с Apple» (chipDk, фирменный знак Apple 18×20 currentColor) и «Продолжить с Google» (контурная, четырёхцветный «G» 18px). Иконка слева от текста, gap 10. Подпись: аккаунт хранит записи об усвоенном и очередь повторов. VK убран.

### 4.2 Сегодня
- Шапка: лого + дата (mono) + аватар-кружок (инициалы) → Профиль.
- Hero-карта повторов (`--heroBg`): кикер `ПОВТОРЫ · СЕГОДНЯ`, «N карточек · ~6 мин», короткая подпись в одну строку. Тап → вкладка Повторы.
- Карточки предметов: имя + уровень (mono), название урока, чип-статус, CTA «Начать →».
- Новый предмет здесь НЕ создаётся (кнопка живёт на вкладке Предметы).

### 4.3 Сессия урока (3 шага: объяснение → выбор → свободный ввод)
- **Объяснение**: кикер `ЗАЧЕМ · миссия…` (amber), заголовок, 2 абзаца, карточка ПРИМЕР (mint), источник с номером и уровнем доверия. CTA «К практике».
- **Практика (выбор)**: вопрос, варианты-карточки; подсказок нет. После «Ответить»: верный — mint + бейдж ВЕРНО, ваш неверный — errBg + ВАШ ВЫБОР; фидбек-карточка «Верно/Не совсем» + объяснение.
- **Практика (ввод)**: инпут + кнопка микрофона (см. 4.7) + подпись «Подсказок нет — разбор откроется после попытки». Проверка по токенам; при ошибке показать «КАК ПРАВИЛЬНО».
- CTA-цепочка: Ответить → Дальше → К разбору.

### 4.4 Разбор (recap)
Вердикт («Чистая сессия» / «Есть что закрепить»), «k из n с первой попытки · Предмет», карточки записей: кикер `УЙДЁТ В ПОВТОРЫ` + интервал (ошибка → «через 1 день», верно → «через 4 дня»), название и заметка. После «Готово» очередь на Сегодня увеличивается.

### 4.5 Повторы
Списки «СЕГОДНЯ» (amber-чипы) и «ПОЗЖЕ» (mint-чипы, opacity .75); записи из пройденных сессий добавляются в «Позже». Кнопка «Начать повторы» закреплена внизу — запускает сессию из карточек очереди.

### 4.6 Новый предмет (4 шага, создаётся с вкладки Предметы)
1. Тема (инпут + чипы-примеры) → 2. Миссия («Зачем вам X?» + пояснение про якорь) → 3. Источники (4 найденных, чипы доверия высокое/среднее/низкое, тап исключает) → 4. План (3 этапа, привязка к миссии, «первый урок соберётся в фоне — без спиннера»).
После «Готово»: карточка предмета в статусе «Готовится…» → через ~4 c «Урок готов». Первый урок — стартовая диагностика (самооценка без правильного ответа + свободный рассказ; всё уходит в записи).

### 4.7 Голосовой ввод
На шаге свободного ввода: кнопка микрофона `--mintInk`; тап → запись (`--err`, ореол, подпись «Слушаю…»), транскрипт печатается в поле по словам (~240 мс/слово); повторный тап — стоп; текст можно править вручную. Голос отключается per-предмет в настройках → кнопка исчезает. Голос никогда не блокирует прогресс: текстовый ввод всегда доступен.

### 4.8 Справочники
- Горизонтальный ряд пиллов предметов (Английский / Quality Assurance / История / …) — предметы не смешиваются; ряд скроллится, если предметов больше трёх.
- Фильтр «Мои слабые места» — янтарный контурный пилл, визуально отличается от предметов (оставляет справочники с ошибками).
- Поиск по всем справочникам (плейсхолдер короткий, всегда помещается в строку).
- Группы: Грамматика / Цель / Глоссарий (у каждого предмета свой глоссарий).
- Карточка: название, чип «слабых: N» (amber), мета «обновлён после урока N · M строк».
- Детальный экран: поиск внутри справочника; компактная таблица «термин (126px) | описание», разделители `--lineSoft`; подразделы mono-заголовками (Настоящее/Прошедшее/Будущее); бейдж ОШИБКА у слабых строк.
- Принцип масштаба: 50 уроков → ~8 справочников по 4–20 строк (конденсация, не 50 документов). Глоссарий растёт линейно → ему обязателен поиск.

### 4.9 Предметы (вкладка)
Заголовок «Предметы · миссия и настройки». Карточка предмета: имя, версия миссии (vN), текущая формулировка (без кавычек, максимум 2 строки с многоточием), зачёркнутая история версий, «Изменить →» (создаёт новую версию, старые не удаляются; поле ввода ограничено 100 символами), шестерёнка → настройки. Внизу закреплена «+ Новый предмет».

### 4.10 Настройки предмета
Шапка приложения с × вместо знака; h1 — название предмета; под ним миссия (`--mut` 13px, ≤2 строк). Скролл-контент: тумблер «Пауза уроков» (повторы продолжают приходить); пиллы «Длительность урока» 3/5/10 мин; «Дневная норма повторов» 10/20/50; «Сложность практики» Комфортно/На пределе; тумблер «Голос в этом курсе» → при включении появляется «Язык распознавания» (14.5px 500, тот же стиль, что заголовок «Голос в этом курсе») с двумя пиллами без подписей: язык интерфейса и язык предмета (для языкового предмета — «Русский / English», по умолчанию язык предмета; для истории и т. п. оба совпадают → показывается «Русский / English»).
Напоминания per-предмет убраны (глобально в Профиле). «Наблюдения системы» и «Сбросить прогресс» убраны.
Внизу закреплена «Удалить предмет» с двухшаговым подтверждением (удаляются и записи, и очередь по предмету).
НЕ добавлять: выбор алгоритма интервалов, ручное редактирование сроков — сроками владеет алгоритм.

### 4.11 Профиль
Без скролла — всё помещается на экран. Шапка приложения с × вместо знака; h1 «Профиль».
- **Карточка аккаунта** (одна строка): слева аватар 44px + имя 16/600 + «вход через Apple/Google» 12px `--mut`; справа два числа 19/600 с подписью 11px: «за месяц» (закрыто карточек) и «сегодня». Никакой геймификации — без стриков и наград.
- **Группы настроек** (заголовок 13px 500 `--mut`, Golos — не mono), каждая — карточка со строками h46 (подпись 14.5px слева, контрол справа, разделители `--lineSoft`):
  - **Напоминания**: «Когда» — сегмент Утро/Вечер; «Тихие выходные» — тумблер.
  - **Повторы**: «Лимит в день» — сегмент 20/40/80/Нет (потолок на всё приложение, поверх норм предметов).
  - **Голос**: «Запись» — сегмент Удерживать / Без рук (push-to-talk vs hands-free). Язык распознавания живёт в предмете.
  - **Приложение**: «Язык» — Русский/English (мгновенно, контент уроков не переводится); «Тема» — Светлая/Тёмная.
- Внизу — контурная «Выйти» с двухшаговым подтверждением: «Записи и очередь повторов останутся на устройстве и в облаке — при повторном входе всё будет на месте» → «Да, выйти» / «Остаться». Выход сбрасывает только токен; локальная БД остаётся привязанной к account id.

## 5. Поведение и правила метода (влияют на UI)

- **Ошибки — память системы**: каждая попытка практики создаёт запись; записи видны в разборе, становятся карточками очереди и метят строки справочников («ОШИБКА»).
- **Подсказок в практике нет** — разбор только после попытки.
- **Диагностика без оценок**: у калибровочных вопросов нет «правильного» ответа — бейдж ПРИНЯТО.
- **Интервалы**: ошибка → 1 день, успех → 4 дня (прототипные значения; в проде FSRS/SM-2).
- **Фоновая генерация**: новые уроки готовятся без спиннера; статус на карточке «Готовится…» → «Урок готов».
- **Миссия версионируется**, история видна и не удаляется.
- **Офлайн**: Повторы и Справочники работают офлайн.
- **i18n**: все строки UI в словаре ru/en (в прототипе — объект `i18n` в логике), контент уроков не переводится. Все подписи должны помещаться в одну строку на 390px — ru и en синхронизированы по длине.
- **Глобальные настройки** (`g`): `rem 'morning'|'evening'`, `weekendOff`, `cap 20|40|80|0`, `mode 'ptt'|'hands'`. Per-предмет (`cfg[id]`): `pause, dur, lim, diff, voice, vlang 'ui'|'lesson'`.

## 6. Технические заметки для порта

- Все стили инлайновые в прототипе; при порте вынести токены таблицы §2 в CSS custom properties, темизация — подменой значений на корне.
- Экраны прототипа: `auth | main(tab: today/reviews/refs/mission) | session | recap | setup | manage | profile | refdetail` — готовая карта роутинга.
- Данные уроков: `{ type: 'explain'|'choice'|'input', … , recTitle, recNote }` — recTitle/recNote = будущая запись LearningRecord.
- Минимальные хит-таргеты 44px (кнопки, пиллы, тумблеры, строки списков).
